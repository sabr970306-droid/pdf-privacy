Privacy Policy — PDF Document Reader

Last updated: September 27, 2026

PDF Document Reader is developed by BigBoss Games.

This privacy policy explains how the application handles user data and documents.

Data Collection

PDF Document Reader does not require a user account and does not collect, sell, or share personal information.

Documents and Files

The application accesses PDF files only when the user selects or opens them. PDF processing is performed locally on the user's device. Documents are not uploaded to BigBoss Games servers.

Advertising and Analytics

The current version of the application does not contain third-party advertising or advertising trackers and does not use analytics services to track user activity.

Internet and Network Use

Core PDF reading and document processing are performed locally on the device. User documents are not uploaded to BigBoss Games servers.

Children's Privacy

The application does not knowingly collect personal information from children.

Changes to This Policy

If the application's data practices change, this Privacy Policy will be updated accordingly.

Политика конфиденциальности — PDF Document Reader

Последнее обновление: 27 сентября 2026 г.

PDF Document Reader разработан BigBoss Games.

В этой политике описывается, как приложение работает с данными пользователя и документами.

Сбор данных

PDF Document Reader не требует создания учетной записи и не собирает, не продает и не передает персональные данные пользователей.

Приложение получает доступ к PDF-файлам только тогда, когда пользователь сам выбирает или открывает их. Обработка PDF выполняется локально на устройстве. Документы не загружаются на серверы BigBoss Games.

Текущая версия приложения не содержит сторонней рекламы или рекламных трекеров и не использует сервисы аналитики для отслеживания активности пользователя.

Интернет и сеть

Основные функции чтения и обработки PDF выполняются локально на устройстве. Пользовательские документы не загружаются на серверы BigBoss Games.

Конфиденциальность детей

Приложение намеренно не собирает персональные данные детей.

Изменения политики
